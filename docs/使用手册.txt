0. 这是什么 / 系统要求
--------------------------------------------------------------------------------
一个 Windows 桌面下载器，特点是把几件成熟的开源工具编排在一起：
  · 下载快：内置 aria2 内核，单文件多连接分片（默认按文件大小自动推荐 1~16 线程，
            也可以在新建任务页给单个任务手动指定）；HLS 并发分片拉取。
  · 能解析：B站/YouTube/抖音/快手/小红书等视频页面、m3u8/HLS 直播、磁力、
            迅雷链接。（网盘分享解析将于下个版本推出。）
  · 能联动：配套 Chromium 浏览器插件，网页上点一下就把视频或视频流送进来。
  · 界面：遵循 Microsoft Fluent 2 设计规范（云母背景、圆角、Fluent 控件）。

系统要求
  · Windows 10 1809 及以上 或 Windows 11（64 位）
  · 内存 4GB 起（建议 8GB）
  · 磁盘空间：程序约 350MB（含 aria2/yt-dlp/ffmpeg 三件套），另需下载文件的
    存放空间
  · 浏览器插件需要 Chrome 88+ / Edge 88+（Manifest V3）
  · 无需管理员权限，无需安装即可运行（绿色版）

1. 目录结构（工程里都有什么）
--------------------------------------------------------------------------------
（下面是源码工程的目录；如果你装的是安装包，程序在 %LOCALAPPDATA%\Programs\YunsuoDownloader，
  结构里的 src\、installer\、test-page\ 不会出现，其它都一样）
下载器工程\
├─ YunsuoDownloader.sln              解决方案文件
├─ installer\                        安装包工程（Inno Setup 脚本 / 图标 / 中文语言包）
├─ src\
│   ├─ YunsuoDownloader.App\         WPF 桌面程序（界面）
│   ├─ YunsuoDownloader.Core\        核心库（引擎/解析/设置/插件服务）
│   └─ YunsuoDownloader.Cli\         命令行工具 ysd.exe（含自检）
├─ extension\                        浏览器插件（Chrome/Edge 未打包扩展；程序里还有一份内置副本）
├─ test-page\                        插件手动测试页（本地服务器 + 测试素材）
├─ tools\                            aria2c.exe / yt-dlp.exe / ffmpeg.exe 等
├─ scripts\                          fetch-tools.ps1 / build.ps1 / build-installer.ps1
├─ docs\                             EULA、使用手册、开源清单、协议文档
└─ downloads\                        默认下载目录

（用安装程序装好之后，这些内容会被放到
  %LOCALAPPDATA%\Programs\云梭下载器\ 下面——安装版看不到 src\ 源码，
  但有 exe、tools\、extension\、docs\ 这些运行时需要的东西。
  extension\ 在程序里还有一份内置副本：就算它被删掉，也能在「浏览器插件」页用
  「导出插件到…」重新导出一份完整的。）

2. 安装与首次运行
--------------------------------------------------------------------------------
方式一（最省事，推荐）：用安装程序
    双击 artifacts\YunsuoDownloader-Setup-1.0.0.exe （约 110 MB）
    向导是简体中文，安装前会展示用户协议与《安装前必读》，安装后会展示
    《安装后请看这里》。一路「下一步」即可，全程不需要管理员权限、不弹 UAC。

      · 安装位置：%LOCALAPPDATA%\Programs\云梭下载器
        即 C:\Users\<你的用户名>\AppData\Local\Programs\云梭下载器
      · 开始菜单会建一个「云梭下载器」文件夹，里面有：
            程序本体 / 浏览器插件目录 / 使用手册 / 用户协议 / 开源项目清单 / 卸载
      · 可选附加任务：创建桌面快捷方式、开机自动启动
      · 卸载：设置 → 应用 → 已安装的应用 → 找到「云梭下载器 下载器」→ 卸载
        也可以用开始菜单里的「卸载 云梭下载器」。
        卸载【不会】删除你的设置，也【不会】删除已下载的文件。
      · 如果安装时提示"安装包被占用"，说明上一次运行的安装向导还没关掉，
        在任务管理器里结束 YunsuoDownloader-Setup-* 进程后重试。

    想自己重新编译安装包：
        powershell -ExecutionPolicy Bypass -File scripts\build-installer.ps1
        （脚本会自动准备 Inno Setup 编译器、图标和中文语言包）
        powershell -ExecutionPolicy Bypass -File scripts\build-installer.ps1 -Verify
        （编译完再做一次静默安装/卸载的往返自检）

方式二（便携版，不写注册表、不建快捷方式）：直接运行编译产物
    src\YunsuoDownloader.App\bin\Debug\net8.0-windows\YunsuoDownloader.exe

方式三：生成一个可独立分发的目录
    在工程根目录执行：  powershell -ExecutionPolicy Bypass -File scripts\build.ps1
    产物在 artifacts\publish\ ，整个目录可以拷贝到任意 Windows 机器直接运行。

第一次运行会弹出**四步引导**（约 30 秒）：
    ① 欢迎与合规提示
    ② 选择下载位置（可以直接改，也可以事后在「设置」里改）
    ③ 下载性能（连接数 / 并发任务数 / HLS 分片数 / 限速）
    ④ 浏览器插件（可跳过；这一页会显示插件目录的路径和来源，找不到时可以点
       「导出插件到…」把程序内置的插件副本释放到你指定的文件夹）
引导结束后，设置会被记住，以后不再出现（除非你手动改回未完成状态）。

★ 如果缺少 aria2c.exe / yt-dlp.exe / ffmpeg.exe
  程序仍能启动，但会降级（只有自研 HTTP 多连接引擎，且无法下载 m3u8）。
  补齐方式（任选一种）：
    · 在工程根目录执行： powershell -ExecutionPolicy Bypass -File scripts\fetch-tools.ps1
    · 或者自己下载后放进 tools\ 目录
    · 或者在「设置 → 外部工具」里手动指定 exe 路径

3. 界面导览（6 个页面）
--------------------------------------------------------------------------------
左侧是 Fluent 风格的导航栏，共 6 项：

【最近下载】（首页）
  · 顶部显示：当前总速度 / 正在下载数 / 排队数
  · 列表每行显示：状态图标、文件名、进度条、状态、大小、速度、剩余时间、
    连接线程数、解析器来源，**右侧固定显示"下载时间"**（以及已用时长）。
  · 行内按钮：暂停 / 继续或重试 / 打开文件 / 打开所在文件夹 / 详情 / 从列表移除。
  · 工具栏：搜索框、筛选（全部/下载中/已完成/失败）、按日期分组开关、
    粘贴链接下载、全部暂停、全部继续、清除已完成、打开目录。
  · 日期分组（v1.1 新增）：默认按「今天 / 昨天 / 本周 / 本月 / 更早」归类，
    点分组标题可以折叠；不想分组的话把工具栏的「按日期分组」取消勾选即可。
  · 支持把链接或 .torrent 文件**直接拖进窗口**添加。

【新建任务】
  · 一个大输入框，支持一次粘贴多条链接（每行一条）。
  · 保存位置可单独指定（不改默认值）。
  · 清晰度下拉框（只对视频页面/HLS 生效）。
  · 下载线程下拉框：默认「自动（程序按文件大小和服务器是否支持分片推荐）」，
    也可以只给这一个任务手动指定 1~32 线程；选中后下面会写清楚为什么是这个值。
  · 「解析预览」：先解析出解析器、类型、文件名、大小；如果是视频页面，还会
    通过 yt-dlp 读出可用清晰度列表。
  · 「开始下载」：批量加入队列。

【网盘解析】
  · 分享链接输入框 + 提取码 + 「解析分享」/「清空」。
  · 登录状态：四家网盘各一行，显示是否已登录，按钮可直接登录 / 退出。
  · 结果区：返回上级、分享标题、当前路径、已选数量、全选 / 清空选择 / 下载选中。
  · 文件列表：勾选框、图标、名称（文件夹可以点进去）、大小、修改时间、复制直链。
  · 底部：状态提示 + 可展开的「解析诊断」。

【浏览器插件】  · 本地服务状态、已连接插件数、最近收到的任务。
  · 连接令牌与「复制令牌 / 复制地址 / 重新生成」。
  · 五步安装指引 + 打开插件目录 + 导出插件到… + 复制插件路径（并显示插件目录的来源）。
  · 能探测到什么（站点清单）。
  · 连不上时的 5 条排查清单。

【设置】
  分为：下载位置、下载性能（线程数策略 / 自动模式上限 / HLS 并发分片数 / 限速）、
  下载行为、外观与运行、浏览器插件、网络与代理、外部工具、更新、数据与维护。
  ★ 所有改动**即时生效并自动保存**，没有"保存"按钮。

【关于与开源致谢】
  · 版本号、检查更新（下载 / 立即安装 / 打开发布页 / 忽略此版本）。
  · 许可、免责与使用文档入口（EULA / 使用手册 / 开源清单）。
  · 开源项目致谢清单（每个项目都带可点击的项目地址）。
  · 运行环境信息（.NET 版本、系统、各目录、外部工具版本、服务状态）。

窗口行为
  · 最小化默认进任务栏（这样才有 Windows 自己的缩小动画）；想在后台常驻，
    可以在「设置 → 外观与运行」勾上「最小化时隐藏到系统托盘」。
  · 点关闭按钮默认隐藏到托盘（不退出程序，可关掉）。
  · 托盘图标双击恢复窗口；右键菜单可"显示主窗口 / 暂停全部 / 继续全部 / 退出"。
  · 任务栏图标会显示总进度。

4. 怎么下载（5 种链接）
--------------------------------------------------------------------------------
把链接粘贴到「新建任务」或首页工具栏的"粘贴链接下载"即可，程序会自动判断类型。

(1) 普通直链
    http(s):// 与 ftp:// 链接。程序先发一个 Range 探测请求，确认服务器是否支持
    分片；支持就自动切成最多 16 个分片并发下载，并记录断点续传状态。

(2) 磁力链接 / BT 种子
    magnet:?xt=urn:btih:...  或 .torrent 文件（拖进窗口或填路径）。
    由 aria2 的 BT 内核处理；默认下载完成后不做种（--seed-time=0）。

(3) 迅雷链接
    thunder://QUFodHRw...    程序会自动 Base64 解码出真实地址再下载。

(4) 视频网站页面
    例如 https://www.bilibili.com/video/BV1xx411c7mD
    支持站点包括：哔哩哔哩、YouTube、抖音、快手、小红书、微博、优酷、爱奇艺、
    腾讯视频、X(Twitter)、Instagram、TikTok、Vimeo、Twitch 等（由 yt-dlp 提供，
    实际支持 1800+ 站点）。
    在「新建任务」里点「解析预览」可以先看清楚有哪些画质再决定。

    ★ 粘贴链接时的常见形态（程序会自动改写成可解析的内容页）：
      · 抖音：https://www.douyin.com/jingxuan?modal_id=数字   →  /video/数字
               https://www.iesdouyin.com/share/video/数字      →  /video/数字
        （不改写的话 yt-dlp 会报 "Unsupported URL"）
      · B 站：https://player.bilibili.com/player.html?bvid=BVxxx → /video/BVxxx
      · YouTube：/embed/xxx 与 youtu.be/xxx → /watch?v=xxx

    ⚠ 三个站点的登录态要求（重要）：
      · 抖音、小红书：必须带 Cookie，否则 yt-dlp 报
        "Fresh cookies (not necessarily logged in) are needed" / "No video formats found"。
        装上浏览器插件并正常登录过一次该站点即可，程序会自动复用那份 Cookie。
      · 快手：yt-dlp **没有**快手提取器，直接粘快手链接一定失败。
        正确做法：在快手网页上打开视频，用**浏览器插件**发送——插件会嗅探到
        真实的 mp4 地址（kwaicdn.com），绕开 yt-dlp 直接下。

(5) m3u8 / HLS 与 mpd / DASH 流
    直接把 .m3u8 地址粘进来即可。程序用 yt-dlp 以 --concurrent-fragments（默认
    16）并发拉取分片，再用 ffmpeg 合并为 MP4。
    · 如果流带 #EXT-X-KEY 加密，浏览器插件会标注"加密"，下载仍会尝试（需要
      key 可公开获取）；真正的 DRM 内容会失败——本程序不做 DRM 破解。
    · 直播流（#EXT-X-ENDLIST 缺失）会持续拉取，停止时点暂停/取消。

(6) 网盘分享链接（下个版本推出）
    百度网盘 / 阿里云盘 / 夸克网盘 / 123 网盘 的分享链接（含提取码）正在做最后验证，
    本版本粘进去会提示「网盘分享解析暂未开放」。详见第 6 节。

5. 浏览器插件：网页一键下载
--------------------------------------------------------------------------------
安装（Chrome / Edge）
  1) 在程序里打开「浏览器插件」页 → 点「打开插件目录」拿到插件路径
     （页面会写明这份插件来自哪里：安装目录 / 工程目录 / 程序在 %AppData% 释放的副本）
  2) 浏览器地址栏输入 chrome://extensions （Edge：edge://extensions）
  3) 打开右上角「开发者模式」
  4) 点「加载已解压的扩展程序」，选中程序给你的那个 extension 文件夹。
  5) 装好后扩展列表里会出现一张卡片，名字是「视频嗅探下载器助手」，
     图标是一个带红点的蓝色播放键。
  6) 点浏览器工具栏上的插件图标 → 打开插件设置 → 把程序里「浏览器插件」页的
     「连接令牌」粘贴进去 → 保存；卡片上的「服务工作进程」显示运行中即成功。

  ⚠ Chrome 137 起，命令行参数 --load-extension 已被官方移除：用快捷方式加这个参数
    启动 Chrome 不会再加载任何插件，而且不会有任何报错——必须用上面的界面方式加载。
  ⚠ 「开发者模式」关掉后，未打包的扩展会被停用/隐藏，别把那个开关关掉。

  插件是内置在程序里的：发布后用的是 exe 同目录的 extension\ 文件夹。
  如果它被误删、或者你只把 YunsuoDownloader.exe 拷到了别的机器（没有一起带 extension\），
  在「浏览器插件」页点「导出插件到…」，选一个文件夹就会重新导出完整的一份
  （共 18 个文件，导出的 manifest.json 与程序内置的完全一致），
  然后照着上面的步骤 2)~6) 加载那个文件夹即可。

使用
  · 打开任意视频网页，插件会自动嗅探媒体请求（webRequest 三层嗅探：扩展名、
    Content-Type、页面内 fetch/XHR 拦截解析 m3u8）。
  · 插件图标上的角标会显示当前页面探测到的媒体数量。
  · 点插件图标 → 列表里勾选想要的条目 → 「发送到下载器」。
  · 列表里会显示：类型（视频/HLS/直链）、清晰度、是否加密、大小、时长、来源。
  · 可以把 m3u8 分片折叠起来（默认折叠），避免列表被几百个 .ts 刷屏。
  · 会一并带上 Referer / User-Agent / Cookie，因此会员内容和防盗链内容通常也能下。

注意事项
  · 程序必须处于运行状态（可以最小化到托盘）。程序没开时插件会把任务排队，
    程序启动后自动补发。
  · 令牌不匹配时插件会显示红色提示，连接会被服务端以关闭码 4001 拒绝。
  · 插件只通过 127.0.0.1 与本程序通信，不连接任何外部服务器。
  · 插件不使用任何第三方 JS 库。
  · 如果你在 Chrome 137 及以上版本里发现工具栏里没有插件图标，请确认是在
    chrome://extensions 里用「加载已解压的扩展程序」装的（命令行 --load-extension
    在 Chrome 137+ 已被官方禁用）。

★ 想快速验证「插件是否真的能嗅探并送到下载器」？
  工程里带了一个零依赖的本地测试页 test-page\：

    方式一：双击 test-page\run.bat
    方式二：命令行  cd test-page  &&  node serve.mjs 8000

  然后浏览器打开 http://127.0.0.1:8000/ 。页面里有：
    · 插入 MP4/WebM、注入 data-src、注入 source 列表  → 验证 DOM 扫描
    · fetch 主列表 / XHR 主列表                       → 验证 MAIN world 的 m3u8 解析
    · 模拟 MSE 播放                                    → 验证 MediaSource/blob 提示
    · 请求直链 mp4                                     → 验证 webRequest 响应头嗅探
    · 第 2 节可以直接在页面里连 ws://127.0.0.1:16888/media 并发送 add 任务
  每点一个按钮，看插件图标上的角标数字是否 +1、弹窗列表是否出现对应条目。
  （这个测试页正是本次交付前用来做真实 Chrome 端到端验证的页面。）


6. 网盘分享解析（百度 / 阿里云盘 / 夸克 / 123）
--------------------------------------------------------------------------------
左侧导航「网盘解析」页，三步：粘链接 → 选文件 → 下载。

  · 支持哪些：百度网盘 / 阿里云盘 / 夸克网盘 / 123 云盘 的分享链接。
    链接里带 ?pwd=xxxx 时提取码会自动识别，也可以在输入框后面手填。
  · 列目录：解析后列出分享里的文件和文件夹。点文件夹名进去，点「返回上级」回来。
  · 批量下载：勾选多个文件 → 「下载选中」；单个文件也可以点右侧的「复制直链」。
  · 登录（重要）：
      - 阿里云盘 / 123 云盘的公开分享一般不需要登录。
      - 百度 / 夸克 多数情况需要登录态。点对应那一行的「登录」，
        会弹出一个内嵌浏览器，你在里面正常扫码或输账号登录，
        登录完点「我已完成登录」，程序把 Cookie 取回来（DPAPI 加密，只存本机）。
      - 内嵌浏览器打不开（系统缺 WebView2 运行时）？两个替代方案：
        (1) 装一下 Microsoft Edge WebView2 Runtime（微软官网免费）；
        (2) 用浏览器插件：在浏览器里登录网盘，插件会把 Cookie 自动同步过来。
  · 解析失败怎么办：展开页面底部的「解析诊断」，里面记录每一步 HTTP 的真实返回。
    把这几行贴到反馈里，就能判断是接口改版还是登录态过期。
  · 已知限制：百度取直链依赖网页端的签名算法，算法更新后会失效（可用插件嗅探兜底）；
    夸克的部分文件需要先转存到自己网盘（程序会自动尝试，没登录时会提示先登录）。

8. 提速技巧（重要）
--------------------------------------------------------------------------------
① 线程数建议先用「自动」（设置 → 下载性能 → 线程数策略）。程序按文件大小和服务器的
   分片能力决定线程数：小文件少开（多线程的建连开销反而比省下的时间多）、大文件多开、
   服务器不支持断点续传时用单线程；单连接被限速的站点可适当多开。
   优先级：单个任务手动指定 > 设置里的固定值 > 自动推荐。
② 发现"线程越多反而越慢"？把「自动模式上限」从 16 调到 8 试试。很多服务器对同一 IP
   的连接数限流，连接开多了互相抢带宽、还容易被拒绝或风控，结果比 8 线程更慢。
   个别慢任务可以在新建任务页给它单独指定线程数（例如 1 个线程）。
③ m3u8/HLS 把「HLS 并发分片数」调到 16~32。HLS 是"很多个小文件"，并发数是
   决定速度的第一因素，比单文件连接数更重要。
④ 同时下载多个任务比给一个任务开更多连接更有效（前提是任务来自不同服务器）。
   把「同时下载任务数」设为 3~5。
⑤ 下载 YouTube 等海外站点，一定要配代理；否则速度会被限。
⑥ 别把文件下到机械硬盘的随机小文件密集目录：HLS 会产生大量分片写入，SSD 更快。
⑦ 如果目标站点本身限速（例如非会员账号），再多的连接也没用——这种情况请
   开通对应服务，或避开高峰时段。
⑧ 关掉「全局限速」（设为 0）。

9. 命令行用法
--------------------------------------------------------------------------------
程序本体 YunsuoDownloader.exe 支持：
  YunsuoDownloader.exe "https://example.com/a.zip"     —— 启动并把该链接加入下载
  YunsuoDownloader.exe --page=settings                  —— 启动后直接打开指定页面
  （页面名：downloads / newtask / extension / settings / about）
  已有一个实例在运行时，新实例会把参数通过本地管道转发给已有实例，不会开第二个窗口。

命令行工具 ysd.exe（src\YunsuoDownloader.Cli）：
  ysd add <url> [url2 ...] [--dir <路径>] [--name <文件名>]   添加并等待下载完成
            [--pwd <提取码>] [--connections N]   N = 本任务线程数，不给就按文件自动推荐
  ysd probe <url>          只解析链接，打印解析器/类型/文件名/大小/引擎建议
  ysd list                 列出历史任务
  ysd extension            显示浏览器插件目录（丢了会自动释放程序内置的副本）
  ysd extension --export <目录>   把内置插件导出到指定目录（发布后别人也能自己导出）
  ysd tools                显示外部工具探测结果
  ysd update               检查更新
  ysd serve                只启动浏览器插件服务（不打开界面），用于调试插件
  ysd selftest             端到端自检（不联网！本地起 HTTP 服务验证各引擎）
       ysd selftest --work <目录>   保留自检工作目录便于排查

10. 数据文件在哪里
--------------------------------------------------------------------------------
设置与数据目录： %AppData%\YunsuoDownloader\
  settings.json          全部设置（含加密后的登录态密文）
  history.json           下载历史（文件名、链接、时间、状态）
  rules.json             自定义解析规则
  logs\YYYY-MM-DD.log    运行日志（保留 7 天，UTF-8 带 BOM，记事本可读）
  engine-state\          自研 HTTP 引擎的断点续传状态文件
  update-cache\          下载下来的新版本安装包

下载文件目录： 默认在你系统的「下载」文件夹下（%USERPROFILE%\Downloads\YunsuoDownloader），
              可在「设置 → 下载位置」里改。

日志是排查问题的第一手资料：出问题时请把 logs\ 里当天的文件一起提供。

11. 常见问题 FAQ
--------------------------------------------------------------------------------
Q：为什么下载速度上不去？
A：先看第 8 节。另外注意：目标站点限速（非会员账号）、单 IP 连接数限制、
   磁盘写入瓶颈都会影响；HLS 请务必调大并发分片数。

Q：m3u8 下载报错 / 只有几 KB？
A：多数是 Referer/Cookie 缺失（防盗链）。用浏览器插件发送任务（插件会带上），
   或者检查该流是否加密/DRM 保护。

Q：视频网站提示"Unsupported URL"或解析失败？
A：yt-dlp 的站点支持是社区日更的。到 https://github.com/yt-dlp/yt-dlp/releases
   下载最新的 yt-dlp.exe 覆盖 tools\yt-dlp.exe 即可。

Q：（下个版本）网盘提示需要 Cookie / errno=-9？
A：见第 6 节，重新获取并设置 Cookie；百度要确认含 BDUSS。

Q：为什么有时文件名很怪？
A：程序优先用插件/页面标题命名。若解析器没给标题，会用 URL 里的文件名。
   可以在「新建任务」里自己填文件名，或下载后用「详情」看真实 URL。

Q：为什么 16 线程反而比 8 线程慢？
A：有些服务器对同一 IP 限连接数或限速，连接多了互相抢带宽，还容易被拒绝/风控；小文件
   多开线程的建连开销也更大。程序默认用「自动」：按文件大小和服务器是否支持分片推荐
   线程数（默认上限 16，可在「设置 → 下载性能」调到 8）。也可以在「新建任务」里给
   这一个任务单独指定线程数。服务器不支持断点续传时，程序会自动用单线程。

Q：点击关闭按钮程序没退出？
A：这是"关闭到托盘"的默认行为（可在设置里关掉）。要真正退出：托盘图标右键 → 退出。

Q：能同时开多个程序实例吗？
A：不能（也不需要）。程序是单实例的，第二次启动会把参数转给已运行的实例。

Q：支持 macOS / Linux 吗？
A：当前版本只针对 Windows（WPF + Windows DPAPI）。

Q：程序会上传我的数据吗？
A：不会。见 EULA 第六条。所有数据都在本机，无遥测。

Q：下载的内容合法吗？
A：请阅读 EULA 第三条。本程序只是工具，内容的合法性由你自己负责。

12. 故障排查
--------------------------------------------------------------------------------
① 先看「关于与开源致谢 → 运行环境」，确认三件套是否都探测到了。
② 看日志：%AppData%\YunsuoDownloader\logs\当天日期.log
③ 插件连不上：
   · 「浏览器插件」页是否显示"运行中"？
   · 令牌是否一致？（插件 popup 出现红色"令牌错误"就是不一致）
   · 端口是否被占用？换一个端口（程序和插件都要改）。
   · 插件目录不见了/被删了？在「浏览器插件」页点「导出插件到…」重新导出一份，
     再到 chrome://extensions 里重新"加载已解压的扩展程序"指向新目录。
   · chrome://extensions 里压根没有「视频嗅探下载器助手」这张卡片？
     按可能性排查：① 第 4 步选错了文件夹（要选直接含 manifest.json 的那一层，
     Chrome 通常会在右下角弹"无法加载清单文件"）；② 用了 --load-extension 快捷方式
     启动（Chrome 137 起这个参数已失效，必须走界面加载）；③ 关掉了「开发者模式」，
     未打包的扩展会被停用/隐藏；④ 加载到了另一个浏览器或另一个 Chrome 用户配置里
     （点右上角头像确认当前是哪个配置）。
④ 下载失败：任务行的红色错误文字就是引擎的原始报错（程序把 aria2 的错误码
   翻译成了中文，例如"资源不存在（404 或分享链接已失效）"）。
⑤ 想复现引擎问题：运行 ysd selftest 做一次不联网的全链路自检，
   它会在本地起 HTTP 服务，验证多连接分片、断点续传、aria2、HLS、插件协议。
⑥ 想重置：删除 %AppData%\YunsuoDownloader\settings.json（会丢失设置与登录态），
   或删除整个 %AppData%\YunsuoDownloader 目录。

13. 卸载
--------------------------------------------------------------------------------
· 程序是绿色的：直接删除程序目录即可。
· 删除数据与设置：删除 %AppData%\YunsuoDownloader 目录。
· 关闭开机自启：设置里取消勾选"开机自动启动"，或删除注册表项
    HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run 下的
    YunsuoDownloader。
· 删除浏览器插件：在扩展管理页点"移除"。
· 下载的文件请自行删除（默认在系统的「下载」文件夹下的 YunsuoDownloader 里）。
