你只需要关联远程并推送：

```powershell

# 1) 关联远程
git remote add origin https://github.com/zxcfdcopud/Yunsuo-downloader.git

# 2) 确认分支名是 main

# 3) 推送（首次会要求登录 / 用凭据管理器或 PAT）
```

### 已经排除的东西（重要）

`.gitignore` 已经挡住以下内容，**不会**被推上去：

| 排除项 | 原因 |
|---|---|
| `dist/`、`artifacts/`、`bin/`、`obj/` | 构建产物（`dist/` 里有 155 MB 的旧安装包） |
| `extension.pem`、`*.crx` | **浏览器扩展的私钥和签名包**——私钥泄露后别人能伪造本插件的签名，绝不能公开 |
| `tools/*.exe` | aria2c / yt-dlp / ffmpeg 二进制（用 `scripts/fetch-tools.ps1` 下载） |
| `website/` | 你正在单独做的官网源码。**如果要一起公开**，把 `.gitignore` 里 `website/` 那一行删掉，再 `git add website` |

> 建仓库时**什么都不要勾**（空仓库），直接推送。

## 二、创建 Release（这一步决定「检查更新」能否工作）

程序读的是这个接口：

```
https://api.github.com/repos/zxcfdcopud/Yunsuo-downloader/releases/latest
```

所以必须发一个**正式 Release**（不能只是 tag），并且：

### 1) Tag 名必须是版本号

用 **`v1.1.0`**（程序会自动去掉开头的 `v`）。

### 2) 上传安装包附件

把下面这个文件上传为 Release 的附件（asset）：

```
artifacts\YunsuoDownloader-Setup-1.1.0.exe
```

程序会从 `assets` 里挑一个文件名匹配 `setup` 且以 `.exe` 结尾的作为下载地址。
建议就保持 `YunsuoDownloader-Setup-1.1.0.exe` 这个名字。

### 3) 填 Release 说明

Release 的正文（body）会原样显示在程序的「检查更新」对话框里。
建议直接用 `CHANGELOG.md` 里 v1.1.0 那段。

### 3.5) 在正文里写清「安装包大小」的字节数（避免每次都被问"大小不对"）

同一个文件有三种写法，很容易被当成"打包错了"：

| 显示位置 | 数值 | 进制 |
|---|---|---|
| 字节数（API / `Get-FileHash` 那类工具） | `163,151,851` 字节 | 精确值，**以这个为准** |
| Windows 资源管理器「大小」列 | `159,328 KB` | 1024 进制（KB = 1024 B） |
| 人话里的 MB | 约 `155.6 MB` | 1024 进制（155.59 MiB） |

所以正文里建议直接写：

```
**安装包大小**：163,151,851 字节（约 155.6 MB）。
Windows 资源管理器显示 159,328 KB —— 只是 1024 / 1000 进制不同，是同一个文件。
```

自查办法（本地 vs 线上必须一致）：

```powershell
(Get-Item artifacts\YunsuoDownloader-Setup-1.1.0.exe).Length          # 字节数
(Get-FileHash artifacts\YunsuoDownloader-Setup-1.1.0.exe -Algorithm SHA256).Hash.ToLower()
# 再和 Release API 里的 assets[0].size / assets[0].digest 对比
```

> 为什么 155 MB 的包能装出 504 MB：Inno Setup 用 LZMA2 ultra 压缩，
> 内核本身解压后约 344 MB（aria2c 5.5 MB + yt-dlp 17 MB + ffmpeg 161 MB + ffprobe 161 MB）。
> 顺带一条：**安装/覆盖前要先退出正在运行的程序**，否则安装程序退出码 1（它会拒绝覆盖运行中的 exe）。

### 4) 发布后自测

```powershell
# 用命令行验证更新源能读到
.\artifacts\publish\ysd.exe update
```

正常应该看到"当前版本 1.1.0 / 已是最新版本"之类的输出。
如果看到「暂时查不到更新信息」，先确认 Release 是 **Published** 状态而不是 Draft。
