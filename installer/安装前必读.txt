安装前必读
================================================================

【这是什么】
  云梭下载器 是一个 Windows 桌面下载器：多线程分片下载、视频网站与
  HLS/m3u8 解析，配套一个浏览器插件可以从网页一键投递任务。（网盘分享链接解析将在下个版本推出。）

【请只下载你有权下载的内容】
  本程序只是工具：不提供、不托管、不索引任何第三方内容，也不绕过任何
  付费墙、会员限制或版权保护技术措施（DRM）。
  请仅下载你自己的文件、已购买且服务条款允许离线保存的内容、公开授权
  （如 CC 协议）或公有领域的作品，并遵守目标网站的服务条款。
  使用本程序下载内容的合法性由你自己负责。详见安装向导里的用户协议。

【安装位置】
  默认按当前用户安装到：
      %LOCALAPPDATA%\Programs\云梭下载器
  这种安装方式不需要管理员权限，所以安装过程不会弹 UAC，也不会弹"安装模式"选择框。
  如果要装到 Program Files 给所有用户用，请把 installer\YunsuoDownloader.iss 里的
  PrivilegesRequired 改成 admin 后重新编译（文件里有注释说明）。

【会安装什么】
  · 桌面程序        YunsuoDownloader.exe
  · 命令行工具      ysd.exe（批量下载 / 解析链接 / 离线自检）
  · tools\          aria2c.exe（多线程下载内核）、yt-dlp.exe（视频/HLS 解析）、
                    ffmpeg.exe + ffprobe.exe（音视频合并与转封装）
  · extension\      浏览器插件（Chrome / Edge，需要手动加载，见下一页）
  · docs\           用户协议、使用手册、开源项目清单

【关于第三方程序与开源许可证】
  tools\ 里的 aria2c.exe 是 GPL-2.0-or-later，ffmpeg.exe 来自带 GPL 组件的
  第三方构建。它们在运行时作为独立进程被调用，代码没有链接进本程序。
  如果你要再次分发本程序（含 tools 目录），请一并附带它们的许可证文本与
  源码获取地址——完整清单见 docs\第三方开源项目清单.txt。

【隐私】
  本程序不含任何遥测。下载历史、设置、登录态（Cookie，用 Windows DPAPI
  加密）全部只保存在你本机：
      %APPDATA%\YunsuoDownloader
  卸载不会删除这个目录，也不会删除你已下载的文件。

点击「下一步」继续。
