安装完成，接下来做这两件事
================================================================

一、装浏览器插件（可选，但强烈推荐）
    1. 打开 Chrome 或 Edge，地址栏输入：
           chrome://extensions      （Edge 用 edge://extensions）
    2. 打开右上角的「开发者模式」开关。
    3. 点击「加载已解压的扩展程序」，选择本程序安装目录下的 extension 文件夹。
       不确定在哪？开始菜单 → 云梭下载器 → 浏览器插件目录，
       或者用程序里「浏览器插件」页的「打开插件目录」按钮。
    4. 打开下载器 → 「浏览器插件」页 → 点「复制令牌」。
    5. 点浏览器工具栏上的插件图标 → 打开插件设置 → 粘贴令牌 → 保存。
       看到「已连接」就成功了。

    装好之后，在 B站 / YouTube / 抖音 / 快手 / 小红书 等网页上点一下插件图标，
    就能把视频或 m3u8 直播直接送进下载器。

二、认识一下界面
    · 最近下载：看进度、速度、剩余时间，以及每一条的「下载时间」。
    · 新建任务：粘贴链接（支持一次粘贴多条，也支持直接拖链接进窗口）。
    · 设置     ：改默认下载位置、并发任务数、单任务连接数、HLS 并发分片数、
                 限速、主题、代理等。改完即时生效。
    · 关于     ：检查更新、查看开源项目致谢与运行环境。

想下载得更快？
    到「设置 → 下载性能」把「单任务连接数」和「HLS 并发分片数」调到 16~32。

找不到文档？
    开始菜单 → 云梭下载器 → 使用手册
    或安装目录下的 docs\使用手册.txt

想卸载？
    设置 → 应用 → 已安装的应用 → 云梭下载器 → 卸载
    （也可以直接用开始菜单里的「卸载 云梭下载器」）
    卸载不会删除你的设置、登录态和已下载的文件；如需清理请手动删除
    %APPDATA%\YunsuoDownloader

祝下载顺利。
