下载器测试页 · YunsuoDownloader

本页用于快速验证浏览器扩展的「嗅探 → 发送」链路。每点一个按钮，对应媒体请求/视频元素就会出现，扩展的角标与弹窗应随之更新。下方面板可直接连接本机下载器的 WebSocket 并发送任务，省去打开插件弹窗。

1. 触发嗅探（让扩展检测到的媒体）

DOM <video src>（渐进式）

直接插入一个带 src 的 <video>（mp4/webm），DOM 层即可扫到。

data-src 播放器

模拟「真实地址藏在 data-src」的站点，扩展会读取该属性。

<source> 标签

插入含多个 <source> 的 <video>。

fetch 抓 m3u8（MAIN world）

触发扩展对 fetch 的 hook，就地解析 HLS 主列表，展开清晰度并标加密。

未请求

XHR 抓 m3u8（带请求头）

触发 XMLHttpRequest hook，验证 Referer/UA/Cookie 等头被采集。

未请求

MSE / MediaSource 播放

创建 MediaSource 喂 blob:，模拟 B 站/YouTube 的 MSE 链路（触发 MSE 提示）。

未触发

直接媒体直链（webRequest）

页面真正请求一个 .mp4 文件（扩展通过 webRequest 嗅到响应头）。

未请求
